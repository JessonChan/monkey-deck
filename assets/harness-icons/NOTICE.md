# 图标版权说明(NOTICE)

本目录(`assets/harness-icons/`)下的 harness 品牌图标,均取自各对应项目的**官方网站或开源仓库**中的官方 logo / favicon,**仅用于 monkey-deck 界面中标识对应的 agent 产品**,不作为本项目的自有品牌使用。

- 各图标的所有权归各自项目方所有,我们不予主张。
- 每个图标的来源见同目录 [`README.md`](./README.md) 的「已知 agent 图标」表(文件 = harness ID,扩展名随源格式)。
- 如果某项目的权利方认为本目录对其图标的收录构成侵权,欢迎**提交 PR 移除对应图标文件**(或直接联系我们),我们会及时处理。

我们尊重各项目的知识产权;本目录仅以「指明产品来源」为目的使用该等标识。
